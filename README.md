# CAD-BOQ Pipeline

**CAD 图纸 → 工程量清单（BOQ）全流程自动化工作流**

识图 → 审图 → 算量 → 编清单 → 组价

</div>

---

## ✨ 功能特性

- **五步流水线**：识图 → 审图（24 条规则）→ 算量（构件模型）→ 编清单（清单-定额映射）→ 组价（取费链）
- **5 专业覆盖**：房屋建筑与装饰 / 安装 / 市政 / 园林绿化 / 钢结构
- **全专业构件化**：24 类构件（柱梁板墙房间、安装 13 类分系统、钢构、市政道路、园林苗木等）
- **工程性质感知**：自动判定新建 / 大修与改造（大修走专属计算器：拆除/翻新/更换）
- **识图必经视觉路径**：渲染 → 多模态模型（qwen3-vl-flash）视觉识别 → 与几何识图交叉验证（v6.5 视觉永不覆盖几何，冲突标待核，交叉验证不能少）
- **数据可信度卡口**：防"编造"——数字三要素校验、来源四级、待提取项不进清单
- **审图规则 24 条**：编码格式 / 量纲 / 价格 / 必填字段 / 跨表一致 / 规范条文（GB 50010 等）
- **多视图支持**：平/立/剖多张图纸自动合并去重，工程性质汇总
- **0 量占位卡口**：算量阶段剔除占位项，独立交付待提取清单
- **多定额组合（v5.16）**：清单项按项目特征组合多子目（如土方=挖装+运土、混凝土=浇筑+泵送），含量=单位换算×厚度/损耗系数
- **特征驱动套定额（v5.17）**：定额子目按清单项目特征/图纸做法条件选取；特征按图纸完善（构造层/做法表/施工说明）
- **自补机制（v5.17）**：国标清单无合适项→自补清单（B类编码）；本册无合适定额→跨册借用（借）；再无→自补定额（补）
- **两段式调用（v5.18）**：识图算量只出无价格清单+计算书+图纸疑问；组价独立触发（--steps 追加组价）
- **仅 Excel 输出（v5.18）**：成果文件只保留 4 个 Excel，中间 JSON 自动清理
- **主材价格库（v5.19）**：268 条真实价（大连信息价/真实询价/经验值），组价按真实价优先，无则经验价
- **构件扣减（v6.0）**：板扣洞 / 墙扣门窗（门窗表 65.7m²）/ 梁柱重叠（-0.36m³）
- **门窗表提取（v6.0）**：表格门窗表 → 门窗号/宽/高/数量/洞口面积（墙扣门窗依据）
- **做法表深化（v6.0）**：多层材料各成装饰分项（细石砼+砂浆找平各 153m²）
- **电气配线（v6.0）**：BV/BYJ 导线规格×配管×根数系数
- **栅格图结构化（v6.0）**：视觉读图返回工程类型/主要构件（OCR 兜底保留）
- **措施项目规则（v6.1）**：measure_rule_items 规则表驱动（脚手架/模板/垂直运输/大型机械/安全文明 10 项）
- **房间分区几何化（v6.1）**：闭合区域→房间（图层/文字标签），做法表部位↔房间→实际分区量（地面=面积/墙面=周长×层高）
- **设计说明专项解析（v6.2）**：识图重点关注设计说明——材料规格型号（800×800/DN25/C30 等 10 类）、做法层次结构化、施工范围、工程概况
- **局部小说明提取（v6.3）**：每张图纸角落注释（做法/材质/规格）独立识别 + 部位关联（最近闭合区域）
- **设计意图推理（v6.3）**：假设-验证引擎——全局理解（性质/用途/概况）+ 算量边界（含/不含项裁剪）+ 参数推断（防水上翻/墙砖高/踢脚等，证据覆盖常识）
- **图例表解析（v6.3）**：图例区符号↔构件（苗木/设备/材料分类）
- **多视图一致性（v6.3）**：平立剖跨图校验（面积/柱梁/层高/门窗 4 维）→ 图纸问题候选
- **规格→主材价联动（v6.3）**：800×800/DN25/C30 规格优先匹配 + 双向主干匹配

## 🚀 快速开始

```bash
# 依赖
pip install -r requirements.txt    # ezdxf, openpyxl, matplotlib

cd scripts

# ① 识图算量段（默认，不含价格）——只出工程量清单(无价格)、工程量计算书、图纸疑问
python pipeline.py 图纸.dxf --steps 识图,审图,算量,编清单

# ② 组价段（明确要求时才调用）——追加定额组价, 出含价格清单+综合单价分析
python pipeline.py 图纸.dxf --steps 识图,审图,算量,编清单,组价
python pipeline.py 图纸.dxf --steps 编清单,组价   # 已有算量结果时只做清单+组价

# 多视图（平立剖多张，自动合并）
python pipeline.py 平面.dxf 立面.dxf 剖面.dxf --steps 识图,审图,算量,编清单

# 输出目录仅保留 Excel 成果（中间 JSON 自动清理）；调试需保留 JSON 加 --keep-json
python pipeline.py 图纸.dxf --steps 识图,审图,算量,编清单,组价 --keep-json

# 指定专业 / 出渲染图
python pipeline.py 图纸.dxf --specialty 市政工程 --render
```

### 视觉识别（可选，识图默认必经）

```bash
# 需要配置 QWEN_API_KEY（阿里云百炼，qwen3-vl-flash）
# 识图自动：渲染 → 视觉识别 → 与几何交叉验证
python pipeline.py 图纸.dxf --steps 识图,审图

# 临时关闭视觉（离线/无 Key）
VISION_OFF=1 python pipeline.py 图纸.dxf

# 独立视觉查询
python vision_query.py 渲染.png --enable-vision
```

## 📁 项目结构

```
cad-boq-pipeline/
├── SKILL.md               # Skill 入口
├── 说明文档.md             # 唯一权威完整说明（架构/能力评估/版本记录）
├── scripts/               # 五步流水线 + 视觉路径 + 测试
│   ├── pipeline.py        # 调度器（--steps 两段式/QC 断言/中间JSON清理）
│   ├── step1_recognize.py # 识图（视觉路径+门窗表+房间检测+文字标注）
│   ├── step2_review.py    # 审图（24 条规则）
│   ├── step3_calculate.py # 算量（构件模型 + 0量卡口）
│   ├── step4_compile_boq.py  # 编清单（特征完善 + 自补清单 B类编码）
│   ├── step5_price.py     # 组价（定额价+主材价 + 多定额组合 + 跨册借用/自补定额）
│   ├── room_geometry.py   # 房间分区几何化（闭合区域→房间→实际分区量）
│   ├── local_notes.py     # 局部小说明提取+部位关联（v6.3）
│   ├── intent_engine.py   # 设计意图推理引擎（假设-验证，v6.3）
│   ├── legend_parser.py   # 图例表解析（符号↔构件，v6.3）
│   ├── design_notes.py    # 设计说明专项解析（v6.2）
│   ├── vision_fusion.py   # 视觉交叉验证（v6.0 视觉优先策略）
│   ├── vision_query.py    # 视觉识别封装（qwen3-vl-flash）
│   ├── render_dxf.py      # DXF→PNG 渲染层
│   └── ...（42 个模块）
├── data/                  # 定额/清单/映射/规范库 + quota_combos.json（组合规则）
├── benchmarks/cases/      # 20 个基准用例（五专业）
├── test_data/             # 测试图纸
└── requirements.txt
```
